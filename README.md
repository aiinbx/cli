# aiinbx CLI

Command line for [aiinbx](https://aiinbx.com): send and read email, forward webhooks to localhost, check domain DNS.

```sh
curl -fsSL https://aiinbx.com/install.sh | sh
npm install -g @aiinbx/cli
```

```powershell
irm https://aiinbx.com/install.ps1 | iex
```

Docs: https://aiinbx.com/docs/cli

This repository holds the release binaries and the agent skill (`npx skills add aiinbx/cli`).
